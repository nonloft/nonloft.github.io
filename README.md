# nonloft.github.io

Персональный сайт-портфолио **nonloft** на GitHub Pages.

## Особенности
- **Интерактивное превью проектов**: по клику на проект запускается фирменная волновая анимация (`wave transition`), открывающая окно с описанием архитектуры, ключевыми фичами и ссылками.
- **Волновой переход (Wave Transition)**: плавный волновой эффект при смене темы оформления и при переходе к проектам.
- **Реалистичный стек без шаблонов**: категоризированные направления разработки (Desktop & GUI, Networking & VPN, Languages, CI/CD & Packaging) вместо искусственных шкал прогресса.
- **Фильтрация проектов**: удобная сортировка по категориям (Десктоп & UI, VPN & Сети, Утилиты).
- **Синхронизация с GitHub API**: динамическое обновление публичной статистики репозиториев.

## Локальный запуск
Просто откройте `index.html` в любом современном браузере или запустите локальный сервер:
```bash
npx serve .
```

## Деплой
Автоматически публикуется на GitHub Pages при обновлении ветки `main`.

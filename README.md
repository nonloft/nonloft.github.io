# Kirillo4ka.github.io

Персональный сайт-портфолио на GitHub Pages.

- Показывает публичные репозитории аккаунта в реальном времени (через GitHub API, с fallback-списком).
- Тёмная/светлая тема с волновой анимацией переключения.
- Анимации: reveal при скролле, дрейфующие градиентные пятна, маркиза стека, подсветка карточек за курсором.

Локальный запуск: просто открой `index.html` в браузере (или `npx serve .`).

Деплой — автоматически при пуше в `main` (GitHub Pages, корень репозитория).
